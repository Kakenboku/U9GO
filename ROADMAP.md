# U9GO UIKit Roadmap

This document tracks planned features and milestones. Community input is welcome — open an issue to discuss any item.

---

## v0.1.0 — Foundation (current)

- [x] Core components: Button, Card, CardGlass, Input, Loading, Logo, ThemeToggle, Navigation
- [x] iOS 26 design tokens (colors, spacing, border radius, typography)
- [x] Dark mode support
- [x] Framer Motion animation system
- [x] Glass morphism visual style
- [x] React 18 + TypeScript + TailwindCSS + Vite stack
- [x] Example pages: Component Showcase, iOS26 Demo
- [x] MIT License + CONTRIBUTING guide

---

## v0.2.0 — More Components

- [ ] `Modal` — full-screen glass overlay with slide-in animation
- [ ] `Switch` — iOS-style toggle with spring physics
- [ ] `Toast` / `Notification` — auto-dismiss, bottom-right stack
- [ ] `Badge` — status indicator with color variants
- [ ] `Avatar` — image + fallback initials
- [ ] `Dropdown` / `Select` — glass-style dropdown menu
- [ ] `Tabs` — underline + pill variants
- [ ] `Slider` — iOS-style range input

---

## v0.3.0 — Page Templates

- [ ] **Login page** — email/password + social sign-in
- [ ] **Dashboard** — stats cards + chart placeholder + sidebar nav
- [ ] **Settings page** — grouped list sections, iOS-style
- [ ] **Product detail page** — hero image, description, CTA
- [ ] **iOS-style list page** — grouped cells with icons, chevrons, badges

---

## v0.4.0 — Developer Experience

- [ ] `npm` package publishing (`@u9go/uikit`)
- [ ] CLI: `npx create-u9go-app` scaffold tool
- [ ] Storybook integration for component docs
- [ ] Figma design tokens export
- [ ] Accessibility audit (WCAG 2.1 AA compliance)

---

## v0.5.0 — AI-Native Features

- [ ] `.cursorrules` templates per component category
- [ ] AI-friendly component comments for better Copilot / Cursor autocomplete
- [ ] Pre-built prompt templates for extending components with Claude / GPT
- [ ] MCP server for design token queries

---

## Long Term

- React Native port of core tokens and components
- Vue 3 adapter
- CSS-only variant (no React dependency)
- Community component registry
